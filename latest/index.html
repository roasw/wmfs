WMFS Documentation¶

WMFS executes ordinary Python tensor calls locally, through an in-process bundled plugin, or in an isolated worker process. The isolated path uses a fixed startup/lifecycle protocol over private SOCK_SEQPACKET sockets, command/completion rings for operations, and shared memfd mappings for tensor payloads.

Documentation Model¶

This is one Sphinx site for both implementation languages:

  • Python API pages are generated from Google-style docstrings by autodoc.

  • C++ API pages are generated from Doxygen comments by Doxygen and Breathe.

  • Architecture and reading guides are MyST Markdown with source-backed literalinclude snippets.

Run just doc to build the complete site reproducibly. Open build/Debug/docs/html/index.html after the default build completes.
