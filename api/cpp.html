class Session¶

Synchronous native client for worker RPC and FD-control traffic.

Session serializes KJ RPC work on its implementation thread. The Python runtime owns process lifecycle and must call close before releasing the worker process.

class MappedBufferCache¶

Validate descriptors and construct zero-copy ATen views over mappings.

Cache mutation is thread-safe. Retiring a cache entry does not unmap a region while retained ATen storage aliases still reference it.
