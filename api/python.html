Plugin operations are dynamic attributes of wmfs. They become available only after Runtime.discover_plugins publishes worker metadata or after an in-process backend is explicitly selected. The reference plugin publishes:

wmfs.matmul(a, b, *, out=None)
wmfs.svd(a, full_matrices=True, *, out=None)
wmfs.add_scalar(a, value, *, out=None)

Other plugins publish their own schema-declared operation names; internal operations are never exposed as module attributes.

Runtime¶

class wmfs.runtime.Runtime¶

Discover plugins and dispatch operations to an execution backend.

close() waits for invocations and discovery accepted before closing, rejects invocations while closing, and then restores constructor defaults. The runtime can be configured and used again after close returns.

Returned managed tensors remain valid after close until their final Torch storage alias is released.
