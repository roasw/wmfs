# Generated v1 compatibility fixture

This directory is an immutable snapshot of artifacts emitted by the first
released `wmfs-tool` format and plugin ABI v1 generator. It is compatibility
input, not generator golden output. Do not regenerate it and do not run the
current `wmfs-tool --check` against it.

The manifest's deployment paths are completed in a temporary directory by the
integration tests. The snapshot intentionally does not include its source
interface or deployment schema so tests cannot regenerate it accidentally.
